# Changelog

## v0.1.0 · 2026-11-18

First public release. Pair a WeChat account with a dedicated Codex instance, keep attributed conversation records, revisit a decision as new information arrives and revise source-linked Obsidian drafts. The bridge also supports restart recovery, background tasks, reminders, public-source monitoring, digests and weekly reviews.

Includes a clean-install CLI, optional user service definitions, a standalone notebook example and account-free integration tests for Linux and macOS.
